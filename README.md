 # 🚀 React App

This project is a simple React application created using Create React App, with dockerized-multi stage build setup in aws ECS Cluster

---

## ⚙️ Setup & Run

1. Install dependencies:
npm install

2. Start the app:
npm start

3. Open in browser:
http://localhost:3000

---

## 📦 Build

To create a production build:
npm run build

---

## 🧪 Test

To run tests:
npm test

---

## 📁 Structure

src/ → Application code  
public/ → Static files  

---

## 🚀 Deployment

Build the project and deploy using:
- Netlify
- Vercel
- AWS S3
